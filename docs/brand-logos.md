# Логотипы марок

Файлы отсюда подставляются в полосу марок автоматически: компонент
`BrandLogo` проверяет наличие `public/brands/<slug>.svg` на этапе сборки.
Нет файла — в плитке вместо знака рисуется название марки шрифтом
заголовков. Ряд от этого не рвётся, и ссылка на страницу марки остаётся.

Slug получается из названия марки: строчные буквы, всё кроме латиницы
и цифр заменяется дефисом. `Hotpoint-Ariston` → `hotpoint-ariston.svg`.

## Требования к файлу

**Имя только строчными буквами.** На Windows регистр в имени не важен,
на боевом Linux — важен. `Beko.svg` соберётся локально и отдаст 404 в проде.

**Формат — SVG.** Растр в полосе марок мылится на ретине и весит больше.

**Фон прозрачный.** Логотипы приглушаются фильтром `grayscale`, и цветная
подложка превращается в серый прямоугольник. Так пришли Zanussi (жёлтый блок)
и Miele (белые буквы на красном) — обоим подложку сняли вручную, у Miele
буквы перекрасили в фирменный красный.

**Только знак, без полей.** Поля вокруг знака скрипт обрежет сам, но лучше
их не иметь: у Bosch знак сидел в квадрате 1:1, реальные пропорции 4.29:1.

**Однотонный или цветной — не важно.** В покое всё обесцвечивается,
в тёмной теме инвертируется. Важно, чтобы знак не был белым на прозрачном:
в светлой теме он исчезнет.

## После добавления файлов

```bash
node scripts/normalize-brand-logos.mjs
```

Скрипт находит настоящие границы содержимого и переписывает `viewBox` по ним.
Без этого логотипы с полями выглядят мельче остальных. Запускать можно
сколько угодно раз — правки применяются только к корневому тегу `<svg>`.

Размер в вёрстке не задаётся вручную: он считается из пропорций так, чтобы
у всех логотипов совпадала занимаемая площадь. Широкий вордмарк получается
ниже, вертикальный знак — выше, и в строке они читаются как равные по весу.

## Где брать файлы

Свободных знаков бытовой техники мало. Проверено на всех 39 марках сайта:

- **Викисклад** — единственный источник с внятной лицензией. Простая
  надпись авторским правом не охраняется, поэтому такие знаки лежат там
  как общественное достояние. Оттуда взяты `ariston`, `candy`, `elica`,
  `liebherr`, `whirlpool`.
- **simple-icons** — из нужных марок есть только Bosch, Siemens, Samsung, LG.
- Российских и малых марок — Атлант, Бирюса, Гефест, Эликор, Krona, Lex,
  Maunfeld, Weissgauff, Darina, Simfer, Shindo, Kuppersberg, Stinol, Nord,
  Jetair, Faber, Cata, Hotpoint-Ariston — в свободных источниках нет
  вообще. Сайты-сборщики логотипов их держат, но раздают чужие товарные
  знаки без прав, и лицензии на файл там нет никакой. Такие марки
  остаются вордмарком, пока не найдётся брендбук производителя.

Осторожно с одноимёнными: на Викискладе `CATA logo.svg` — транспортная
компания из Массачусетса, `Faber and Faber` — лондонское издательство,
`Nord Pool` — энергобиржа. Название совпало, марка — нет.

## Правовое

Логотипы производителей — товарные знаки правообладателей. Использовать их
для обозначения обслуживаемой техники допустимо, но файлы должны быть
из официальных брендбуков, а не из поиска по картинкам.

Свободная лицензия на файл товарного знака не отменяет. Показывать знак
можно так, чтобы читалось «мы это чиним», и нельзя так, чтобы читалось
«мы — их сервис». Поэтому знаки идут ровным приглушённым рядом, без слов
«официальный» и «авторизованный» рядом.
