# АвантФикс — выездной ремонт крупной бытовой техники

SEO-сайт под Яндекс для трёх городов Белгородской области.
Astro 7, статическая генерация, ноль JS-фреймворков в рантайме.

## Мультирегиональность

Три отдельных сайта в Яндекс.Вебмастере, каждый со своим регионом:

| Сборка | Хост | Регион |
|---|---|---|
| `belgorod` | `avantfix.ru` | Белгород |
| `oskol` | `staryj-oskol.avantfix.ru` | Старый Оскол |
| `gubkin` | `gubkin.avantfix.ru` | Губкин |

`belgorod.avantfix.ru` зарезервирован и отдаёт 301 на apex.

Главный домен отдан Белгороду намеренно: отдельный «областной» сайт был бы
почти дублем белгородского и рисковал склейкой как аффилиат.

### Почему сборка на каждый город отдельная

`SITE_CITY` задаёт город на этапе билда. Каждая сборка получает собственные
`site`, `canonical`, `sitemap.xml` и свой каталог `dist/<city>/`.
Город не подставляется в рантайме — тексты по городам физически разные файлы.
Это защита от фильтра дорвеев: Яндекс склеивает и понижает поддомены,
отличающиеся только названием города.

**Правило:** совпадение текста между городами не выше 40–50%. У каждого города
свои цены (`priceFactor`), свой телефон, свои районы, свои мастера, свои отзывы.

## Команды

```bash
npm install
npm run dev            # Белгород, localhost:4321
npm run dev:oskol      # Старый Оскол
npm run dev:gubkin     # Губкин
npm run build          # все три сборки в dist/{belgorod,oskol,gubkin}
npm run check          # проверка типов и Astro-диагностика
```

## Структура

```
src/
  config/site.ts       организация: домен, реквизиты, гарантия, соцсети
  data/cities.ts       3 города: склонения, телефоны, гео, районы, priceFactor
  data/appliances.ts   6 видов техники: склонения, бренды, неисправности, прайс
  data/brands.ts       заметки по маркам: что ломается, доступность запчастей
  data/copy.ts         тексты хабов — свои на каждую пару «город × техника»
  data/reviews.ts      отзывы (пусто: только настоящие)
  lib/                 форматирование, цены, SEO-хелперы, сборка JSON-LD
  layouts/             базовый layout: мета, микроразметка, Метрика
  components/          переиспользуемые блоки
  pages/               маршруты, включая генерацию по данным
  styles/              дизайн-токены и глобальные стили
deploy/                nginx, systemd, обработчик заявок, инструкция
```

Русские падежи хранятся явными полями (`genitivePlural`, `prepSingular`,
`inPrep`, `dative`), а не выводятся правилами. Автосклонение ломается
на «Старом Осколе» и «духовом шкафу», а кривой заголовок — это и потеря CTR,
и сигнал низкого качества.

## Карта страниц

На каждом городском сайте:

```
/                                          главная
/remont-stiralnyh-mashin/                  6 хабов по видам техники
/remont-stiralnyh-mashin/ceny/             прайс
/remont-stiralnyh-mashin/bosch/            бренды (топ-15 на вид)
/remont-stiralnyh-mashin/ne-slivaet-vodu/  неисправности
/o-kompanii/ /garantiya/ /otzyvy/ /kontakty/
/politika-konfidencialnosti/ /soglasie/
/blog/
```

**Запускать волнами.** Сначала главная + 6 хабов + прайсы + коммерческие
страницы. Дальше по 20–40 страниц в месяц. Единовременный выброс сотен
шаблонных страниц на молодом домене — прямой путь под фильтр.

## Деплой

Статика на российский VPS, Nginx, три vhost'а. РФ-хостинг обязателен:
это и требование 152-ФЗ к хранению персональных данных, и сигнал
региональности, и TTFB 20–50 мс по области.

Одна команда на сервере под root — она же разворачивает с нуля, она же
обновляет до свежего коммита:

```bash
curl -fsSL https://raw.githubusercontent.com/ProstyGospody/avantfixv2/main/deploy/bootstrap.sh | bash
```

Сервер сам собирает сайт из репозитория. Выпуски лежат рядом,
переключение — симлинком, откат секундный. Подробности
в [deploy/README.md](deploy/README.md).

Nginx на каждый хост: HTTP/2, Brotli, `Cache-Control: public, max-age=31536000,
immutable` на `/_a/`, `no-cache` на HTML, HSTS, 301 с www и с http.

## Чек-лист вне кода

Технический аспект сайта — только половина. Что определяет позиции дополнительно:

- [ ] **Регистрация ИП** — без ИНН/ОГРН не пройти верификацию в Яндекс Бизнесе,
      а карточка в Картах стоит выше органики по локальным запросам
- [ ] **Яндекс Бизнес** — 3 карточки, заполнение на 100%, фото, прайс, посты
- [ ] **Поток настоящих отзывов** — 5–10 в месяц на карточку. Накрутка ловится
- [ ] **Яндекс.Вебмастер** — 3 хоста, регион на каждый, sitemap, оригинальные тексты
- [ ] **Яндекс.Метрика** — свой счётчик на поддомен, цели, Вебвизор.
      Поведенческие факторы — главный фактор ранжирования в Яндексе
- [ ] **Городские номера** — 4722 / 4725 / 47241, кликабельные, в шапке
- [ ] **Реквизиты в подвале** — ИП, ИНН, ОГРНИП
- [ ] **Юридическое** — политика конфиденциальности, согласие на обработку ПД
      чекбоксом, уведомление в Роскомнадзор как оператор ПД
- [ ] **Внешние площадки** — 2ГИС, Zoon, Yell, Flamp, Авито, Профи, VK, Telegram.
      Ссылочные прогоны и биржи на молодом домене — не использовать
- [ ] **Никаких аффилиатов** — второй сайт по той же услуге в том же городе
      с теми же телефонами Яндекс склеит и оставит один

## Аудит

```bash
npm run build && npm run audit
```

`scripts/audit.mjs` проверяет то, что ломается тихо и всплывает уже в выдаче:
длину и уникальность title и description, единственность h1, canonical
с правильным хостом, валидность JSON-LD, вес страницы — и главное,
схожесть контента между городами.

Последний прогон:

| Тип страниц | Схожесть между городами (макс.) |
|---|---|
| Хабы услуг | 26% |
| Прайсы | 33% |
| Неисправности | 36% |
| Главная | 36% |
| Страницы марок | 39% |

Порог — 50%, выше него аудит падает. Это не формальность: в первой версии
неисправности совпадали на 87%, а прайсы на 82%, потому что уникальными были
только вводные абзацы, а FAQ, шаги ремонта и пояснения к цене — общими.
Такой набор поддоменов Яндекс склеивает и понижает как дорвеи.
Лечится тем, что каждый повторяющийся блок пишется отдельно на каждый город:
см. `data/faq.ts`, `data/faultCopy.ts`, `STEPS_COPY` и `PRICE_COPY` в `data/copy.ts`.

**При добавлении города или шаблона тексты пишутся заново, а не копируются
с заменой топонима.** Аудит это поймает.
